LESSON ONE

HTML: Build the page

Learn how webpages organize their content.

What is HTML?

HTML means HyperText Markup Language. It tells a browser what content exists on a page and how that content is organized.

For example, a heading tells the browser, “This is a heading.” A paragraph tells it, “This is a block of text.”

Example: HTML 
<h1>Hello, Lana!</h1>
<p>Welcome to my first website.</p>
<button>Click me</button>
💡

Remember: HTML creates the elements. It does not automatically decide all their colors or give every button a custom action.

Explore the HTML topics

1. Tags and elements

Tags are the markup inside angle brackets. Many elements use an opening tag and a closing tag.

<p>This is a paragraph.</p>
<h2>This is a smaller heading.</h2>

The closing tag has a slash. Some elements, like <img>, do not need a closing tag.

2. Attributes, links, and images

Attributes give elements extra information. A link uses href for its destination. An image uses src for its image file.

<a href="about.html">About me</a>
<img src="flower.jpg" alt="A pink flower">

Useful descriptive alt text helps people using screen readers and provides context if an image cannot load.

3. Classes and IDs

Classes and IDs help CSS and JavaScript find specific elements.

<p class="welcome">Hello!</p>
<button id="saveButton">Save</button>

A class can be shared by many elements. An ID should be unique within the page.

4. Forms and page structure

HTML can create forms, input fields, lists, tables, navigation menus, and meaningful page sections.

<label for="name">Your name</label>
<input id="name" name="name">
<button type="submit">Send</button>

HTML forms can collect information. Saving it securely or sending it somewhere usually requires additional JavaScript and/or server-side code.

5. What can HTML be used for?
  • Personal websites and portfolios
  • Articles, blogs, and documentation
  • Online store product pages
  • Forms, sign-in screens, and navigation
  • Media pages and learning resources

LESSON TWO

CSS: Design the page

Learn how to make content look the way you want.

What is CSS?

CSS means Cascading Style Sheets. It describes how HTML elements should look, where they should appear, and how they should respond to different screen sizes.

Example: CSS 
body {
  background: #f4efff;
  font-family: Arial, sans-serif;
}

h1 {
  color: purple;
}

button {
  padding: 12px 20px;
  border-radius: 10px;
}
💡

Remember: CSS needs elements to style. If your CSS selector does not match an element, that rule will not style it.

Explore the CSS topics

1. Selectors, properties, and values

In h1 { color: purple; }, h1 is the selector, color is the property, and purple is its value.

.card { background: white; }
#mainTitle { font-size: 32px; }

A dot selects a class. A hash selects an ID.

2. Layout, spacing, and size

CSS can arrange elements using Flexbox and Grid, control space using margin and padding, and manage widths and heights.

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

This creates three equal columns when there is enough room. On a small screen, you might change it to one column.

3. Responsive design

Responsive design helps a website work on phones, tablets, and computers.

@media (max-width: 600px) {
  .cards {
    grid-template-columns: 1fr;
  }
}

This rule switches the grid to one column when the viewport is 600 pixels wide or less.

4. Animations and interactive states

CSS can animate movement, fading, and color changes. Hover and focus states can help people understand which controls they can use.

button {
  transition: transform .2s ease;
}

button:hover {
  transform: translateY(-2px);
}

Keep motion comfortable, and make sure keyboard users can see which element has focus.

5. What can CSS be used for?
  • Colors, fonts, gradients, and backgrounds
  • Menus, cards, columns, and page layouts
  • Transitions and animations
  • Responsive mobile-friendly layouts
  • Visual themes and accessible focus states

LESSON THREE

JavaScript: Make it work

Learn how websites respond to actions and information.

What is JavaScript?

JavaScript is a programming language. It can respond to clicks, check answers, update text, calculate totals, and work with information.

Example: JavaScript 
const button = document.querySelector("#helloButton");

button.addEventListener("click", () => {
  alert("Hello! The button works!");
});
💡

Remember: JavaScript can change the page, but it needs to find the correct HTML elements and use the right instructions.

Explore the JavaScript topics

1. Variables and information

Variables let a program keep track of information. Text is called a string, numbers represent numeric values, and booleans are either true or false.

const learner = "Lana";
let score = 0;
const isReady = true;

Use const when you will not reassign the variable. Use let when the variable needs to change.

2. Functions and decisions

A function groups instructions. Conditions let your program choose what to do based on information.

function checkScore(score) {
  if (score >= 5) {
    return "Great job!";
  }
  return "Keep practicing!";
}
3. Events and buttons

An event happens when something occurs, such as a click. An event listener tells JavaScript what to do when that event happens.

button.addEventListener("click", () => {
  message.textContent = "You clicked!";
});

The variables button and message must refer to existing elements for this example to work.

4. Forms, storage, and APIs

JavaScript can read form values, check inputs, store simple preferences in the browser, and request data from APIs.

Browser storage is not a secure place for passwords or secrets. Private accounts, sensitive records, and protected permissions require a secure backend.

5. What can JavaScript be used for?
  • Quizzes, games, and calculators
  • Menus, tabs, and interactive controls
  • Forms and validation
  • Dashboards, charts, and filters
  • Loading and updating data
  • Web applications and server-side programming with suitable tools

PUTTING IT ALL TOGETHER

One website. Three jobs.

Here is what happens when you build a button that changes a message.

1

HTML creates it

<p id="message">Hello!</p>
<button id="changeButton">
  Change message
</button>

The page now has a paragraph and a button.

2

CSS styles it

button {
  background: purple;
  color: white;
  padding: 12px;
}

The button gets its appearance and spacing.

3

JavaScript adds action

changeButton.addEventListener(
  "click", () => {
    message.textContent = "You did it!";
  }
);

Clicking the button changes the paragraph.

🧩

Why keep the files separate?

Separate files make a project easier to read, update, and debug. HTML holds the page content, CSS handles the design, and JavaScript handles behavior. They connect through HTML elements, CSS selectors, and JavaScript references.
